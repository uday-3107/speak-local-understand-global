System Architecture

Built for uncompromising privacy and performance entirely on-device.

memory

Offline Engine

A specialized integration of faster-whisper (STT) and Meta's NLLB-200 (MT), optimized to run locally without internet dependency, ensuring zero data leakage.

school

Academic Assistant

Powered by a local LLM (Ollama / Mistral) built for academic discourse — it polishes drafts, explains terminology, and writes study notes in the student's language.

database

Local Storage

Transcripts, translations, and recordings are stored in an on-premise PostgreSQL database served alongside the app — complete ownership of your educational data.
